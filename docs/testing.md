# 验收范围

公开源码中的回归测试使用临时目录与模拟 app-server；不登录账户，不发起真实模型请求，不读取个人笔记。

- `run-workflow.py`：独立保存、冲突保护、损坏恢复、编辑草稿、原件追加、去重、来源历史、移动后的身份修复、保守图片清理，以及原文件/资料流程回归。
- `run-daily.py`：日常草稿、聊天连续性、搜索、按需上下文、原件更新、发送安全、输入法和输入框行为。
- `test_bridge.py`：版本核对、边界与链接保护、事务恢复、引用和重新定位。
- `test_init_workspace.py`：最小协作目录接入、拒绝覆盖既有配置、保留已有登记。

运行命令见 README。Swift 测试需要 macOS 与 Xcode Command Line Tools；它们会在 `macos/.build` 生成可删除的测试二进制。测试可证明本地流程，不替代所有 Codex 服务版本和 macOS 系统权限的真实兼容性验证。

公开截图另用合成数据运行真实视图；演示数据不进入正式应用启动流程或安装包。
