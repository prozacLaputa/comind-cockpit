# 接入已有笔记

需要 Python 3、一个已有 Markdown / Obsidian 笔记库，以及一个单独用于协作规则与桥接工具的目录。笔记库原文件、日记、模板和插件保持原样；不要将私人笔记提交到公开源码仓库。

从本仓库运行：

```bash
python3 tools/init_workspace.py --workspace "$HOME/CoMindWorkspace" --notes "/absolute/path/to/existing-vault"
```

请把 `--notes` 改成现有笔记库的绝对路径。`--workspace` 必须是尚不存在的新目录；工具拒绝覆盖已有协作目录，不扫描笔记正文。它创建最小协作规则、通用桥接脚本和本机绑定；仅在笔记库没有 `.comind/registry.json` 时创建空登记表，保留现有登记。笔记目录不会被搬迁，也不会新建正文库。

然后在应用「设置 → 数据」选择刚创建的协作目录。到阵地「资料」关联已有原笔记，分别决定哪些可用于聊天、默认写回哪一份。关联不代表迁移，也不自动启用后台定时任务。原件变更后后续聊天读取最新版。

工具生成的通用协作规则只是起点，可在自己的目录内调整。不要给 AI 整个文件系统的默认写入许可；明确写回目标，AI 推断和冲突留待核对。原件暂不可用时先恢复来源，不能另建替代库。

已有完整 CoMind 工作区无需运行初始化工具，直接选择它即可。不要对现有工作区重复初始化，也不要把作者的私人配置复制给自己。
