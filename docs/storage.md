# 存储与恢复

| 内容 | 位置 / 规则 |
| --- | --- |
| 原笔记正文 | 用户选择的现有 Markdown / Obsidian 笔记库 |
| 协作规则与工具 | 用户选择的协作目录 |
| 本机笔记根绑定 | 协作目录 `.local/knowledge-sources.json` |
| 原件身份登记与整理回执 | 笔记库 `.comind/` 元数据；不是另一份正文库 |
| 原件修改历史与编辑草稿 | 原件的同域历史目录；避免放入通用应用索引 |
| 阵地、引用、UI、聊天草稿、队列 | iCloud Drive / CoMind 驾驶舱；读取错误时不覆盖损坏文件 |
| Codex 原会话与登录 | 由本机 Codex 管理，不随本仓库发布 |

聊天只使用阵地已授权的来源。每次发送会核对原件版本并选择相关内容；上下文不是无限的，引用文件也不等于发送其全部内容。外部更新后以原件为准。

编辑和追加先读版本，再写入并保留历史。遇到冲突，请先保留草稿、读取最新版并核对；不要通过删除状态文件来跳过冲突。重新定位需要选择原件并核对身份，不能把同名文件直接当成原件。

恢复入口允许重试、保存工作副本、重新读取以及恢复可用草稿。工作副本可能包含未发送的私人文字，请与笔记一样保管。云端同步由系统负责；本地保存成功不保证其他设备已经收到。

清理图片有保留期，保护已发送、当前引用、恢复副本引用及无法确定来源的文件。这里清理的是应用副本，不是用户选择图片时的原始文件。
